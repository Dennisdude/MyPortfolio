# My Portfolio

Welcome to my personal portfolio website! This site showcases my projects, skills, and experience as a developer.

## About

This is a React-based portfolio built with Vite, featuring sections for my hero introduction, projects, skills, and contact information. It includes a dynamic star background and theme toggle for a modern, interactive experience.

## Technologies Used

- React
- Vite
- JavaScript
- CSS

## Sections

- **Hero**: Introduction and overview
- **About**: More details about me
- **Skills**: Technical skills and expertise
- **Projects**: Showcase of my work
- **Contact**: Ways to get in touch
